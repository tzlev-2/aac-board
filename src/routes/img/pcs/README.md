## למה נתיב-שרת ולא `static/`

הסמל נצרך ב-`<img src>`. אילו הוגש מדומיין נפרד מאחורי Access, הבקשה
הייתה **subresource חוצה-אתר** והקוקי היה נחסם ב-Safari וב-Firefox
כברירת-מחדל. כאן — אותו origin, אותה כניסה, בלי קוקיז צד-שלישי.

ומול העתקת הקבצים ל-`static/`: הדלי נשאר מקור-אמת יחיד, ובייטים מורשים
אינם משוכפלים לכל ארטיפקט-בילד.
