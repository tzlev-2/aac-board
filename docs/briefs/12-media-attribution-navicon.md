## פריט 1 — מדיה מוטמעת · `parse.ts:97`

```ts
const files = unzipSync(bytes, { filter: (file) => /\.xml$/i.test(file.name) });
```

הפילטר מונע פרישה של כל מה שאינו XML, ולכן **מדיה מוטמעת לעולם אינה
מגיעה למודל.** ההערה בקוד אומרת "מי שיצטרך מסיר את ה-filter בשורה אחת" —
זה לא מדויק: להסיר אותו לגמרי מפרישה **את כל נפח הקובץ לזיכרון**.

**מה נדרש:**
1. פרישה **עצלה** — לשמור את ה-`Uint8Array` רק לקבצים שיש אליהם הפניה מתא,
   לא את כל הארכיון. ‏`.gridset` מצורף מגיע למאות MB.
2. ‏`ImageRef` ב-`types.ts` צריך להבחין בין הפניית-ספרייה להפניה-מוטמעת.
3. הפותר ב-`symbols.ts` מחזיר `blob:` URL למוטמע — **ולשחרר אותו**
   (`URL.revokeObjectURL`) כשהלוח מוחלף, אחרת דליפה.
4. ‏`emf`/`wmf` **אינם נתמכים בדפדפן.** אל תתחזה שכן. אם ההפניה היא לאחד
   מהם — ליפול לשכבה הבאה בדיוק כמו מזהה שאינו במניפסט, ולתעד את זה.
5. ‏`mp3` — ‏`org-1` מכיל אחד. אם זה זול, לחווט; אם לא, **לומר במפורש
   שלא נעשה** ולמה.

**אימות חובה:** לטעון `org-3` בבילד ולהראות שהתמונות המוטמעות מוצגות.
‏`org-1` **אינו** מוכיח כלום כאן — יש בו אפס.
