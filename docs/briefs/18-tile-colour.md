## §3 — הארכיטקטורה

### §3.1 — המודל שנמדד, מול מה שיש לנו

| | Grid | אצלנו היום |
|---|---|---|
| מלבן-התא המלא | **`TileColour`** | **לא מצויר** — רואים את רקע-`GridBoard` |
| הקופסה המוסטת | ‏`BackColour` + `BackgroundShape` | ‏`.cell` ‏(`verticalFillGradient`) |
| המרווח | חלק ממלבן-התא | ‏`padding`+`gap` על `.grid` (`--gutter`) |

🔑 **ההסטה כבר קיימת אצלנו.** ‏`.cell` הוא **בדיוק** קופסת-ה-`BackColour`.
⇒ אזור-המשבצת של תא = **שטח-הרשת שלו, מורחב אל תוך המרזב**.

### §3.2 — הגאומטריה שנמדדה

על `shots/eng-03-b037-kbd-empty.png` (‏1920×1080), שתי השורות העליונות שכל
תאיהן נושאים `TileColour #FFFFFFFF`:

| מה נמדד | התוצאה | המסקנה |
|---|---|---|
| סריקה אופקית ב-`y=160` · `200` · `240` | לבן **מ-`x=0` עד `x=1919`** | המשבצת מגיעה ל**קצה הלוח**, כולל ה-`padding` |
| סריקה אנכית ב-`x=960` | הלבן הראשון ב-`y=30` = קצה-הלוח העליון | אותו דבר אנכית |
| שורת-מקלדת (‏`y=700`, בלי `TileColour`) | רצפי רקע-דף של ‏16–17px בין מקשים | המרזב עצמו, ‏`g≈21px` פחות צל |

⇒ **הכלל:**

```
משבצת = שטח-הרשת של התא
       + --gutter/2   לכל צד הפונה לשכן
       + --gutter     לכל צד הפונה לקצה-הלוח
```

‏**חצי-מרזב בין שכנים** הוא הפיצול היחיד שמוגדר היטב כששתי שכנות נושאות
צבעים שונים. ‏**מרזב מלא בקצה** הוא מה שנמדד. שתי שכנות באותו צבע נפגשות
בלי תפר — וזה בדיוק מה שהצילום מראה.

🛑 **מה שלא נמדד:** איך Grid מפצל את המרזב כששתי שכנות נושאות `TileColour`
**שונה**. בצילום כולן לבנות. ‏⇒ ‏**חצי-חצי היא ההכרעה שלנו**, ונושאת
`// 🛑 לא-מאומת מול Grid` בקוד.

### §3.3 — 🛑 השכבה יושבת ב-`GridBoard`, **לא** ב-`GridCell`

שתי סיבות, שתיהן מחייבות:

1. ‏`.cell` נושא `overflow: hidden`, ‏`border-radius`, ולעיתים `clip-path`
   ‏(`GridCell.svelte:75-78`). ‏**משבצת שתצויר מתוכו תיחתך** — והמדידה אומרת
   שהיא **מלבן חד**.
2. ‏**סלייס 16 עורך את `GridCell.svelte` במקביל.** נגיעה שלך שם = קונפליקט-מיזוג
   על קובץ שאינך בעליו.

**המימוש:** בתוך ה-`{#each drawnCells}` ב-`GridBoard.svelte`, לצד כל
`<GridCell>` — `<div class="tile" aria-hidden="true">` שממוקם על **אותו**
`grid-column`/`grid-row`, עם `margin` שלילי לפי §3.2 ו-`z-index` **מתחת** ל-`.cell`.

**ציור מותנה:** צייר את ה-`<div>` **רק** כש-`gridColourToRgb(cell.style.tileColour).a > 0`.
🔑 ל-`org-1/2/3` יש `0` מופעים ⇒ ‏**ה-DOM שלהם לא משתנה כלל**, ואף בדיקה
קיימת ואף צילום-ייחוס קיים אינם נוגעים. זו מיטיגציית-הרגרסיה העיקרית.

### §3.4 — ‏`--gutter` — לאמת, לא להניח

‏`--gutter` מוגדר על `.grid` ‏(`GridBoard.svelte:115`), והמשבצת היא **ילדה של
`.grid`** ⇒ הוא אמור לרשת. 🛑 **ודא זאת בפועל.** ההערה בראש `visualDefaults.ts`
מתעדת כשל זהה שכבר קרה: ‏`opacity` חזר ל-1 **בלי שום שגיאה** כשה-var לא הוגדר.

### §3.5 — זיהוי קצה-הלוח

`GridBoard` כבר מחזיק את `page.rows` ואת `page.columns` (ראו `columnTemplate`).
לכל תא:

```
inline-start-edge : cell.x === 0
inline-end-edge   : cell.x + cell.columnSpan === page.columns
block-start-edge  : cell.y === 0
block-end-edge    : cell.y + cell.rowSpan === page.rows
```

🛑 ‏`.grid` נושא `direction: rtl` — השתמש ב**מאפיינים לוגיים**
(`margin-inline-start/end`), לא ב-`left`/`right`. הפרויקט אוכף את זה.
